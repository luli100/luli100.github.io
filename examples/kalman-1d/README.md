# 一维卡尔曼滤波：实验验证

配套文章：[从零推导一维卡尔曼滤波](https://luli100.github.io/kalman-filter-1d/)。

需要 Python 3.7 及以上，只用标准库。在本目录运行：

```powershell
python kalman_1d.py
```

| 实验 | 验证内容 |
| --- | --- |
| 实验一 | 对大量随机误差直接统计融合后的方差，与 `(1-K)^2 P + K^2 R` 对比；最小值出现在 `K = P/(P+R)` |
| 实验二（1） | `Q = 0` 时增益 `K` 持续趋近 0；`Q > 0` 时收敛到稳态值 |
| 实验二（2）（3） | 前车刹车后，`Q = 0` 的滤波器发散；`Q = 0.01` 能跟上，但因速度写死仍比雷达原始读数差 |

随机数种子固定为 1，结果可复现。
